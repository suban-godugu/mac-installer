Install Verilumen on a Mac

Finished version 0.1.0. Download the file that matches your Mac, then follow the four steps.

1. Check your Mac

Click the Apple menu, then About This Mac.

If it says Chip and Apple M1, M2, M3, or M4, use Apple Silicon. If it says Processor and Intel, use Intel.

Download for Apple Silicon M1, M2, M3, and M4 Macs Download for Intel Older Macs that say Intel

2. Put the app in Applications

  1. Open the downloaded file. It ends in .dmg.
  2. Drag Verilumen Prospect Intelligence Browser onto the Applications folder.
  3. Open Applications. Hold Control and click the app, choose Open, then choose Open again.
  4. Google Chrome must already be installed. The app uses Chrome for research.

Apple blocks the first open because this app is not signed. Control-click, then Open, is the normal way past that warning. After the first open, a normal double-click works.

If the disk image will not open

Apple Silicon zip · Intel zip

Unzip it, move the app into Applications, then use the same Control-click Open step.
